Bana bir kitap sitesi projesi yap. Üniversite ödevi için yapıyorum, backend + frontend + veritabanı olacak.

Teknolojiler:
- Backend: Python Flask
- Frontend: React (Vite)
- Veritabanı: MySQL
- CSS: Tailwind CSS

==========================================================
BACKEND
==========================================================

backend/ klasörüne yap.

Flask ile REST API oluştur. Yapı basit olsun:

backend/
├── app.py
├── config.py
├── models.py        (tek dosyada tüm modeller)
├── routes/
│   ├── auth.py
│   ├── books.py
│   └── reviews.py
├── seed.py
├── requirements.txt
└── .env

### Veritabanı Tabloları (models.py içinde hepsi):

User:
- id, username, email, password_hash, created_at

Book:
- id, title, author, description, isbn, cover_image_url, page_count, published_year, created_at

Category:
- id, name

book_category: (ara tablo, many-to-many)
- book_id, category_id

Review:
- id, user_id, book_id, rating (1-5), comment, created_at

SQLAlchemy kullan. İlişkileri tanımla.

### API Endpointleri:

Auth:
- POST /api/auth/register → kayıt ol
- POST /api/auth/login → giriş yap, JWT token döndür
- GET /api/auth/me → token ile kullanıcı bilgisi al

Kitaplar:
- GET /api/books → kitapları listele (sayfalama: ?page=1&per_page=10)
- GET /api/books/<id> → kitap detayı (yorumlarıyla beraber)
- POST /api/books → kitap ekle (giriş gerekli)
- PUT /api/books/<id> → kitap güncelle (giriş gerekli)
- DELETE /api/books/<id> → kitap sil (giriş gerekli)
- GET /api/books/search?q=kelime → kitap ara (title ve author'da arasın)
- GET /api/books?category=id → kategoriye göre filtrele

Yorumlar:
- GET /api/books/<id>/reviews → yorumları getir
- POST /api/books/<id>/reviews → yorum yaz (giriş gerekli)

Kategoriler:
- GET /api/categories → kategorileri listele

### api.js
- Axios instance oluştur
- baseURL: http://localhost:5000/api
- Request interceptor: localStorage'dan token varsa header'a ekle

### AuthContext.jsx
- login, logout, user state'leri
- Token'ı localStorage'da tut
- Sayfa yenilenince token'dan kullanıcıyı çek

### Sayfalar:

Home.jsx:
- Basit bir karşılama bölümü, "Kitap Dünyası" başlığı
- Son eklenen 4 kitap (BookCard ile göster)
- Kategoriler listesi (tıklanınca Books sayfasına filtreli gitsin)

Books.jsx:
- Tüm kitaplar grid halinde (BookCard)
- Üstte bir arama kutusu
- Kategori filtresi (dropdown veya butonlar)
- Basit sayfalama (Önceki / Sonraki butonları)

BookDetail.jsx:
- Kitap bilgileri (başlık, yazar, açıklama, sayfa sayısı, yıl, isbn)
- Kapak görseli (yoksa basit bir placeholder div)
- Kategorileri göster
- Ortalama puan
- Yorumlar listesi
- Giriş yapılmışsa: yorum ekleme formu (rating seçimi + yorum yazma)

Login.jsx:
- Email ve şifre
- Giriş butonu
- Hata mesajı göster
- "Hesabın yok mu? Kayıt ol" linki

Register.jsx:
- Username, email, şifre alanları
- Kayıt butonu
- Başarılıysa login sayfasına yönlendir

AddBook.jsx: (sadece giriş yapanlar görsün)
- Kitap ekleme formu (title, author, description, isbn, cover_image_url, page_count, published_year)
- Kategori seçimi (checkbox)
- Ekleyince kitaplar sayfasına yönlendir

Navbar.jsx:
- Sol: "Kitap Sitesi" yazısı (ana sayfaya link)
- Orta: Kitaplar linki
- Sağ: giriş yapılmamışsa Giriş/Kayıt, yapılmışsa kullanıcı adı + Kitap Ekle + Çıkış

BookCard.jsx:
- Kitap adı, yazar, kısa açıklama (max 80 karakter)
- Puan (varsa yıldız sayısı)
- Tıklanınca detay sayfasına gitsin

ProtectedRoute.jsx:
- Giriş yapılmamışsa login sayfasına yönlendirsin
